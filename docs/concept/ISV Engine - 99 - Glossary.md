# ISV Engine: Glossary

## Purpose and Context

This glossary provides an alphabetical overview of key terms and components used in the Intrinsic Software Value (ISV) Engine.

## Terms

- A1 (Data Value): Measures how strongly a software change affects database structures, entities, or data models.
- A2 (UX Multiplier): Adjusts value based on UI complexity, from no UI to highly interactive custom screens.
- B1 (Logic Value): Represents complexity of business rules, transformations, and algorithms.
- C1 (Integration Factor): Measures difficulty of connecting to external systems, third-party APIs, or new infrastructure.
- C2 (State Factor): Represents technical debt friction. Poor system health increases ISV.
- Calibration: Process that derives the relationship between abstract ISV points and actual development time.
- Confidence Score: AI certainty measure for requirement analysis. Low values indicate refinement risk.
- D3 (Quality Multiplier): Optional factor that increases ISV for elevated quality requirements such as audits or mandatory automated testing.
- Digital Twin: Machine-readable map of the current architecture used as baseline.
- Fact Finder: Automated scanner (Status Quo Miner) that builds the digital twin from source code.
- Gap Analyzer: AI component that compares new requirements with current capabilities to identify structural gaps.
- Intrinsic Software Value (ISV): Objective, dimensionless number for structural size and complexity of a requirement.
- Knowledge-Based Value (KBV): Time booked for activities without direct code changes, such as meetings, admin, or research.
- Ship Rate: Empirical conversion rate from ISV points to hours or costs.
- Ship Unit Cluster: Logical grouping of related tasks (for example story plus subtasks) evaluated as one unit.
- system_context.json: File produced by the Fact Finder that captures current system capabilities and patterns.
- Valuation Engine: Component that applies the ISV formula to generate final score.
- Value Metrology: Overall philosophy of objective structural value measurement instead of subjective time estimation.
