# Architecture

Architecture-focused documentation for organizing and evolving the ISV project.

## Purpose

This folder captures structural decisions, documentation architecture, and future implementation direction.

## Contents Overview

- `architecture.md` — high-level implementation architecture: folder structure, layer responsibilities, dependency rules, use-case analysis, batch processing architecture (concurrency model, data store, layer placement).
- `techstack.md` — technology stack decisions: TypeScript, Node.js 24 LTS, pnpm, decided and planned library choices.

Future content:
- decision notes (context, options, chosen direction, rationale).

## How to Use

- Add lightweight architecture notes when decisions are made.
- Prefer one focused document per decision/topic.
- Keep references aligned with `README.md` and `CONTRIBUTING.md` when structure changes.
