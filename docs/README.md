# Docs

Project documentation hub for the Intrinsic Software Valuation (ISV) initiative.

## Purpose

This folder contains all documentation that defines, explains, and evolves the ISV model.

## Contents Overview

- `concept/` — core conceptual building blocks, methods, and glossary
- `architecture/` — architecture notes, structural decisions, and evolution guidance
- `qa-strategy.md` — test philosophy, tier definitions, naming conventions, and rules

## How to Use

- Start in `concept/` to understand the model and terminology.
- Use `architecture/` for decisions about structure, process, and future implementation direction.
- Keep cross-links updated when adding or moving docs.

## Contribution Note

Each subfolder in `docs/` must include its own `README.md` with purpose, content overview, and usage guidance.
