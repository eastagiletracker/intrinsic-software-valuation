# Roadmap

Strategic implementation roadmap for the ISV Engine.

## Purpose

Tracks the sequence of milestones, quality gates, and architectural review checkpoints from the current state (domain schemas + client adapters) to a fully operational end-to-end pipeline.

## Contents

| File | Description |
| --- | --- |
| `roadmap.md` | Full milestone plan with dependency graph, quality gates, and review steps |

## How to use

- Read `roadmap.md` for the current plan and progress tracking.
- Each milestone and quality gate has a checkbox — mark completed when done.
- Quality gates define automated tests that must pass before the next phase starts.
